# Kyna Interior & Konstruksi

Landing page untuk Kyna Interior & Konstruksi Lampung.

## Tech stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Lucide React

## Development

```bash
npm install
npm run dev
```

Buka http://localhost:3000.

## Quality checks

```bash
npm run typecheck
npm run lint
npm run build
```

## Content notes

- Kontak, alamat, rating, dan ringkasan ulasan dimasukkan berdasarkan informasi bisnis yang diberikan.
- Foto pada hero, section tentang, dan grid proyek saat ini adalah foto referensi dari Unsplash, bukan dokumentasi proyek Kyna. Ganti dengan foto proyek asli sebelum website dipublikasikan.
- Data jam operasional sengaja tidak dicantumkan karena belum diverifikasi.
- Sesuaikan metadata/domain dan tautan sosial setelah akses domain serta akun resmi dikonfirmasi.
